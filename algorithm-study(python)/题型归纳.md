# 二分查找
二分查找的核心不是“数组必须有序”，而是：**候选答案具有单调性，每次用 mid 判断后能排除一半候选区间**。有序数组只是最常见的单调场景。
## 题型一 二分查找
在有序数组中找 target
```python
# 找第一个满足 check(x) 的位置：最小可行值
l, r = 最小可能, 最大可能
while l < r:
    mid = l + (r - l) // 2
    if check(mid):
        r = mid
    else:
        l = mid + 1
return l
```
## 题型二 二分答案
典型问法：最小化最大值、最大化最小值、最少天数、最小容量。
```python
def maxDistance(position: list[int], m: int) -> int:
    position.sort()
    # 贪心验证：在“最小间距 >= d”的约束下，最多能放几个球
    def can_place(d: int) -> bool:
        count = 1
        last = position[0]
        for x in position[1:]:
            if x - last >= d:
                count += 1
                last = x
                if count >= m:
                    return True
        return False
    # 二分答案：找“最大的可行 d”
    lo = 1                                   # 最小可能间距
    hi = position[-1] - position[0]          # 最大可能间距
    ans = 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if can_place(mid):
            ans = mid          # mid 可行 → 记录，并尝试更大
            lo = mid + 1
        else:
            hi = mid - 1       # mid 不可行 → 缩小

    return ans
```
