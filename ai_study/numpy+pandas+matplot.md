## 分箱 cut
### 1. 基本语法
```python

pandas.cut(
    x,
    bins,
    right=True,
    labels=None,
    retbins=False,
    precision=3,
    include_lowest=False,
    duplicates='raise',
    ordered=True
)
```

### 2. 核心参数详解

| 参数               | 说明                                                                                                                                          |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `x`              | 要分箱的一维数组、列表或 Series。不能是 DataFrame。                                                                                                          |
| `bins`           | 分箱方式，有三种形式：  <br>① **整数**：将 `x` 的最小值到最大值等宽分成 `bins` 个区间。  <br>② **标量序列**：自定义边界，如 `[0, 18, 35, 60, 100]`。  <br>③ **IntervalIndex**：直接指定区间索引。 |
| `right`          | 区间是否包含右端点，默认 `True`，即 `(a, b]`；若为 `False`，则为 `[a, b)`。                                                                                      |
| `labels`         | 自定义每个箱的标签。可以是数组，长度必须等于箱数；若为 `False`，则返回整数编码（0, 1, 2...）。默认 `None`，返回区间对象。                                                                   |
| `retbins`        | 是否返回分箱边界。默认 `False`；设为 `True` 时返回 `(结果, 边界数组)`。                                                                                             |
| `precision`      | 区间标签的精度，默认 3 位小数。                                                                                                                           |
| `include_lowest` | 是否包含最低值。默认 `False`。当 `right=True` 且使用自定义边界时，最低区间为 `(a, b]`，若数据最小值恰好等于 `a`，会变成 `NaN`。设为 `True` 后最低区间变为 `[a, b]`。                             |
| `duplicates`     | 当自定义边界中存在重复值时如何处理。默认 `'raise'` 报错，可设为 `'drop'` 删除重复边界。                                                                                      |
| `ordered`        | 返回的 Categorical 是否有序，默认 `True`。                                                                                                             |
## axis参数含义的探讨
#### 1. 聚合函数：axis 是“要折叠掉的轴”
- `axis=0`：沿着行轴往下加，把“行”折叠掉，所以结果是**每列一个值**。
    
- `axis=1`：沿着列轴往右加，把“列”折叠掉，所以结果是**每行一个值**。
    

所以有人会说 `axis=0` 是“按列计算”，但更准确地说：

> `axis=0` 是沿着行方向计算，跨行，最后每列得到一个结果。
#### 2. `drop`：axis 是“要删除标签所在的轴”
这里：

- `axis=0` 表示在 index 轴上删标签，所以删行。
    
- `axis=1` 表示在 columns 轴上删标签，所以删列。
    

所以 `drop` 里 `axis=0` 又像是“行”，这不是矛盾，而是因为：

> `drop` 的 axis 指“标签所在轴”，不是“计算方向”。
