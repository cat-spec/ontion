### 列表推导式
```python
带筛选：只要偶数，且算出平方
even_squares = [i * i for i in range(5) if i % 2 == 0]
# 正确写法（三元写在左边，不过滤）：
[x if x % 2 == 0 else -1 for x in range(5)]  # [0, -1, 2, -1, 4]
```
```推导式底层逻辑
# 等价于 (执行顺序：先 i=0，再 i=1，再 i=2)
squares = []
for i in range(3):
    squares.append(i*i)
```

字典推导式
```
original = {'name': '小明', 'age': 18}
# 推导式（这里 for 左边有 k, v 两个变量）
new_dict = {v: k for k, v in original.items()}
# 结果：{'小明': 'name', 18: 'age'}
```
**对应关系**：`original.items()` 每次吐出 `('name', '小明')`，Python 不管它叫 `k,v` 还是 `x,y`，只管**按顺序**把 `'name'` 塞给第一个变量，把 `'小明'` 塞给第二个变量。

# 变量修饰符
## 1. 作用域声明关键字

|名称|作用|
|---|---|
|默认|函数内赋值就是局部变量|
|`global`|声明变量是模块全局变量|
|`nonlocal`|声明变量是最近外层函数的变量|
|没有 `static`|Python 没有函数内静态局部变量|
|没有 `local`|不写就是局部，不需要声明|
### global
因为 `global` 不是给变量打标签，而是**告诉当前这个函数**：

> 我函数体里的这个名字，去模块全局找，不要在局部创建。

它只对当前函数体生效，不会自动传给嵌套函数。
### nonlocal
告诉当前函数去最近的上一个函数找变量，而不是自己创建。
# 对象
### 实例方法、类方法、静态方法的区别

| 类型                   | 第一个参数  | 能访问什么          | 典型场景               |
| -------------------- | ------ | -------------- | ------------------ |
| 实例方法                 | `self` | 实例属性 + 类属性     | 操作具体对象的状态          |
| 类方法 `@classmethod`   | `cls`  | 类属性，不能直接访问实例属性 | 工厂方法、操作类级状态        |
| 静态方法 `@staticmethod` | 无      | 不自动访问类或实例      | 逻辑上属于类、但不依赖状态的工具函数 |

###  魔法方法
### 2.1 构造与初始化

| 方法                    | 触发时机         | 使用场景                                           |
| --------------------- | ------------ | ---------------------------------------------- |
| `__new__(cls, ...)`   | 对象**创建**之前   | 继承不可变类型（`int`、`str`、`tuple`）时；需要控制实例创建过程（如单例）时 |
| `__init__(self, ...)` | 对象创建后**初始化** | 给实例属性赋初始值，绝大多数类的起点                             |
| `__del__(self)`       | 对象被垃圾回收时     | **不应依赖**它做资源清理；资源管理优先使用 `with` / `__exit__`    |
### 2.2 对象的字符串表示

|方法|面向谁|使用场景|
|---|---|---|
|`__str__`|最终用户|`print(obj)`、`str(obj)`，返回可读性好的描述|
|`__repr__`|开发者 / 解释器|调试、交互式环境、容器打印，目标是**准确**，理想情况下 `eval(repr(obj))` 能重建对象|
|`__format__`|f-string / `format()`|自定义格式化行为，较少需要手写|

如果只实现一个，优先实现 `__repr__`，因为 `__str__` 的默认回退就是 `__repr__`。
### 2.3 容器协议：让对象像列表/字典一样工作

| 方法             | 对应语法                       |
| -------------- | -------------------------- |
| `__len__`      | `len(obj)`                 |
| `__getitem__`  | `obj[key]`、`obj[index]`、切片 |
| `__setitem__`  | `obj[key] = value` 修改值     |
| `__delitem__`  | `del obj[key]`             |
| `__contains__` | `x in obj`                 |
| `__iter__`     | `for x in obj`             |
| `__next__`     | `next(obj)`（迭代器协议）         |
### 2.4 比较与哈希

| 方法                                        | 对应运算                             |
| ----------------------------------------- | -------------------------------- |
| `__eq__` / `__ne__`                       | `==` / `!=`                      |
| `__lt__` / `__le__` / `__gt__` / `__ge__` | `<` / `<=` / `>` / `>=`          |
| `__hash__`                                | `hash(obj)`，用于 `set` 和 `dict` 的键 |
### 2.5 可调用对象：`__call__`

定义了 `__call__` 的实例可以像函数一样加括号调用。使用场景：需要“携带状态的函数”——例如一个带计数器的回调、一个配置好的转换器、一个装饰器类。
### 2.6 上下文管理器：`__enter__` / `__exit__`

`with` 语句在进入时调用 `__enter__`，离开时**一定会**调用 `__exit__`，即使代码块内抛出异常。使用场景：文件、网络连接、锁、数据库事务等任何需要**确定释放**的资源。
