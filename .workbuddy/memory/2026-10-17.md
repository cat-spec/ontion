## 本机 git 推送要点（重要，下次直接用）

- WorkBuddy 内置 PortableGit 的系统 gitconfig 强制 `credential.helper=helper-selector`，无 TTY 时会静默 exit 1 且**无任何报错输出**，push 看似失败。
- 绕过的正确写法（用 Windows 凭据管理器里已保存的 gho_ token）：
  `git -c credential.helper= -c credential.helper=wincred push origin main`
  空值 `-c credential.helper=` 用于清空 helper 列表，否则 selector 仍会执行。
- 调试无输出的命令时：重定向到 `C:\Users\123\.workbuddy\ssh_tmp\` 下再读取（写入 `~/.ssh`、`F:\` 根目录会被沙箱拦截）。
