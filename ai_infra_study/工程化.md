## Path
```python
from pathlib import Path

# 当前工作目录
print(Path.cwd())

# 当前 Python 文件的路径
print(Path(__file__).resolve())

# 当前文件所在目录
print(Path(__file__).resolve().parent)

#随意拼接
ROOT = Path(__file__).resolve().parent
DATA_DIR = ROOT / "data"
```

## argparse
分离出元数据出来，每次修改无需修改源码，只用在运行时候填写参数
```python
import argparse
#创建arg类
parser = argparse.ArgumentParser(
    description="PyTorch Training"
)
# 添加参数
parser.add_argument(
    "--epochs",
    type=int,
    default=10,
    help="训练轮数"
)

parser.add_argument(
    "--lr",
    type=float,
    default=0.001,
    help="学习率"
)

args = parser.parse_args()

print(args.epochs)
print(args.lr)
```

| 参数         | 作用      | 示例                                  |
| ---------- | ------- | ----------------------------------- |
| `type`     | 数据类型    | `type=int`                          |
| `default`  | 默认值     | `default=32`                        |
| `required` | 是否必须传入  | `required=True`                     |
| `choices`  | 限制可选值   | `choices=["cpu","cuda"]`            |
| `help`     | 帮助说明    | `help="Batch size"`                 |
| `action`   | 指定参数行为  | `action="store_true"`布尔开关，填写了就为true |
| `nargs`    | 接受几个值   | `nargs="+"`                         |
| `dest`     | 指定结果属性名 | `dest="batch_size"`                 |
## 日志logging
print与logging
这个写法没有问题，但如果项目规模变大，就会遇到几个困难：
- 无法方便地区分普通信息与错误信息。
    
- 不容易同时输出到终端和文件。
    
- 不容易记录时间、模块、错误位置。
    
- 运行时间很长时，不方便保留历史日志。
    
- 多个模块的输出难以统一管理。
```python
# 创建 Loggerlogger = logging.getLogger("trainer")  
logger.setLevel(logging.DEBUG)  
  
# 格式  
formatter = logging.Formatter(  
    "%(asctime)s | %(levelname)s | %(message)s"  
)

# 终端 Handlerconsole = logging.StreamHandler(sys.stdout)  
console.setLevel(logging.DEBUG)  
console.setFormatter(formatter)  
  
# 文件 Handlerfile_handler = logging.FileHandler(  
    log_dir / "train.log",  
    encoding="utf-8"  
)  
file_handler.setLevel(logging.DEBUG)  
file_handler.setFormatter(formatter)

# 连接 Logger 与 
Handlerlogger.addHandler(console)  
logger.addHandler(file_handler)

#打印调试
logger.info("Training started")
```

## Time
cpu间测量
```python
import time
start = time.perf_counter()

output = model(x)

elapsed = time.perf_counter() - start

```
gpu间测量
```python
start_event = torch.cuda.Event(enable_timing=True)
end_event = torch.cuda.Event(enable_timing=True)

start_event.record()

output = model(x)

end_event.record()
end_event.synchronize()

elapsed_ms = start_event.elapsed_time(end_event)

print(f"GPU elapsed: {elapsed_ms:.3f} ms")
```
